# HomewardBound
Lightweight Unturned Home Teleport Plugin
Allows players to use the /home command to teleport back to their claimed bed.

To install the plugin, either use the release dll or build it using the source code. Put this code on the server in the "Modules" folder and add the .module file alongside it. Finally, restart the server and the plugin will be installed.

Requires unturned Assembly-CSharp.dll, UnityEngine.CoreModule.dll, and com.rlabrecque.steamworks.net.dll for building.
